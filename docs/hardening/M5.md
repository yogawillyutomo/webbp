# WEBBP M5 — Accessibility & Motion Safety

Baseline `main`: `ff2e3d4282bede0b77ce9cd6d7d13e2965635361`

## Objective

M5 improves keyboard operation, focus management, landmarks, assistive-technology semantics, and reduced-motion behavior without changing product scope.

## Changes

### Landmarks and skip navigation

- add a visible-on-focus "Lewati ke konten utama" skip link;
- establish one `main` landmark;
- make the main landmark programmatically focusable;
- replace the Navbar brand heading with a home link so the page does not have a duplicate top-level heading.

### Mobile navigation

- expose menu state with `aria-expanded` and `aria-controls`;
- provide an accessible open/close label;
- render the full-screen menu only while open so hidden links are not tabbable;
- trap Tab/Shift+Tab inside the open menu;
- close with Escape;
- return focus to the menu trigger;
- lock and restore body scrolling;
- expose current-section state with `aria-current="location"`.

### Service cards

- make expandable cards keyboard-operable using Enter and Space;
- expose expanded state with `aria-expanded`;
- bind cards to their detail region using `aria-controls`;
- keep collapsed detail content out of the accessibility tree;
- add visible keyboard focus treatment.

### Product dialog

- retain `role="dialog"`, `aria-modal`, and labelled heading;
- move focus into the dialog on open;
- trap Tab/Shift+Tab inside the dialog;
- close with Escape;
- restore focus to the product card that opened it;
- preserve body-scroll locking;
- expose product cards with `aria-haspopup="dialog"`.

### Reduced motion

- wrap Framer Motion with `MotionConfig reducedMotion="user"`;
- disable hero pointer/parallax work when reduced motion is requested;
- do not run the decorative SVG shimmer animation for reduced-motion users;
- make portfolio filter auto-scroll non-smooth when reduced motion is requested;
- add CSS fallback that collapses non-essential CSS animation and transition duration;
- disable smooth page scrolling under reduced motion.

### Decorative semantics

- Hero cube interaction that only toggled decorative badges is removed instead of being exposed as a misleading control;
- Hero cube and hero badges are hidden from assistive technology;
- duplicate adjacent Footer logo alt text is removed.

### Additional consistency

- Footer service labels are aligned with the evidence-led M3 capability list;
- Footer "Portfolio" becomes "Produk";
- Footer section headings use a consistent `h2` level;
- product filter buttons expose selection with `aria-pressed`.

## Deferred

This tranche does not claim formal WCAG conformance or automated accessibility certification. Manual keyboard, screen-reader, responsive, contrast, and reduced-motion UAT remain required before making such a claim.

## Merge gate

Before merge:

```bash
npm ci
npm audit
npm audit --omit=dev
npm run verify
git diff --check
```

Manual smoke checks:
- Tab reaches the skip link first;
- skip link moves focus to main content;
- mobile menu opens by keyboard, traps focus, closes with Escape, and restores focus;
- ServiceCard toggles with Enter and Space;
- product modal receives focus, traps Tab, closes with Escape, and restores focus to its card;
- reduced-motion OS preference removes non-essential motion;
- exact-head Vercel preview succeeds.
