# WEBBP M3 — Portfolio Truth & Product Proof

Baseline `main`: `1cb017fe65ab515b9b5837e8b035d82561c184a5`

## Objective

M3 replaces the generic agency-style portfolio with a public product view that follows current Bakaran Project engineering evidence.

The public site must not imply that a prototype is production-ready, invent product capabilities, use unrelated stock/random imagery as proof, or publish private repository links as if they were product pages.

## Evidence policy

Repository, canonical product documentation, merged implementation, CI/UAT evidence, and explicit product status remain the source of truth.

Public wording is intentionally more conservative than internal engineering detail.

Random Picsum images are removed.

## M3 merge gate

Before merge:

```bash
npm ci
npm audit
npm audit --omit=dev
npm run verify
```

Additional checks:
- no `picsum.photos` remains in active portfolio code
- no legacy generic featured project is presented as current product proof
- no private repository URL is exposed in public UI
- SINGGAH has no real-world accuracy claim
- current Vercel preview must be successful
